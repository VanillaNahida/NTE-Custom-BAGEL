# 功能特性

- **跨服通用**：国服 国际服通用，无需区分版本
- **多分辨率支持**：支持 720P、1080P、1440P 窗口分辨率拍摄的照片替换
- **图片自动处理**：自动将选中的图片缩放到适配游戏的分辨率，无需手动编辑

# 使用方法

教程视频：[https://www.xcnahida.cn/archives/MFb9rQFg](https://www.xcnahida.cn/archives/MFb9rQFg)

## 使用说明

1. 首先不要启动游戏启动器，先启动 `异环呗果图片上传器.exe`，这个exe可以从[Release](https://github.com/VanillaNahida/NTE-Custom-BAGEL/releases)页面下载 
 
2. 选择你要上传的图片，点击启动按钮，此时会弹出一个黑窗口。不要关掉它  

3. 进入启动器后，修改启动器的设置中，勾选使用 **DX11** 来启动游戏，否则必定会失败 

4. 然后用启动器进入游戏，`launcher.exe` 的窗口上出现 `HTGame.exe running. You can keep this window open or close it.` 即为注入成功
 
5. 进入游戏后进入拍照界面后，按下 **F9** 开始捕获替换，拍照，拍照完成后再按一次 **F9** 即可结束捕获替换

6. 进入游戏后，如果登录一直不成功，请重新启动游戏

## 注意事项
 
- 进入游戏后，在拍照前**千万不可以按下 F9**，后果自负  
- 如果需要更换图片，请在主界面点击选择图片按钮，注入器会自动替换。
- 进入拍照界面后，按下 **F9** 开始捕获替换，拍照，拍照完成后再按一次 **F9** 即可结束捕获替换  
> [!WARNING]
> 如果你不在拍照完成后按下 **F9**，会导致你界面的所有图片都会被替换掉！  
- 仅支持 **720P**、**1080P**、**1440P** 的窗口分辨率拍摄的照片，否则替换会失败，图片大了你也上传不上去  
- 如果登录一直不成功，请重新启动游戏
